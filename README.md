# Дежурный

AI-ассистент для команды разработки: вставляете ошибку, лог, код или вопрос — получаете карточку с причиной, планом, кодом и оценкой срочности и уверенности.

## Запуск

Нужен Node.js 22.9+. Зависимостей нет.

1. Скопируйте `.env.example` в `.env`, впишите `PROXYAPI_KEY`.
2. `npm start` и откройте http://localhost:3000.
3. `npm test` — тесты конвейера и валидации (сеть подменена, ключ не нужен).

В `.env` можно поменять `MODEL` (по умолчанию `openai/gpt-5.4`) и `TRIAGE_MODEL` (`openai/gpt-5.4-nano`).

## Как устроено

Запрос проходит простой конвейер (`harness.js`), стадии которого видны в интерфейсе:

1. **Разбор.** Быстрая модель определяет тип (ошибка, инструкция, объяснение, ревью, не по теме), технологию и срочность. Если вопрос не про разработку, основная модель не вызывается вовсе.
2. **Ответ.** Основная модель получает общий промпт и дополнение под тип вопроса (`prompts.js`): диагностика, кратчайшая инструкция, объяснение через аналогию или ревью кода. Ответ строго в JSON по схеме.
3. **Проверка.** Ответ приводится к схеме (`normalize`). Если формат сломан, модель получает причину и один раз исправляет ответ. После второй неудачи пользователь видит понятную ошибку.

Дополнительно: подсказки следующих вопросов сохраняют контекст предыдущего ответа, а вставленный код и логи в промпте считаются данными, а не инструкциями.

## Решения

- **Тема.** Разбор ошибок не требует внутренней документации компании.
- **Backend.** `node:http` без зависимостей. Ключ остаётся на сервере. Стадии идут в браузер построчным JSON (NDJSON).
- **Интерфейс.** Карточка с цветом срочности, шкалой уверенности, чек-листом шагов, подсветкой кода и отдельным копированием кода и всего ответа.
- **История.** Последние 5 запросов с готовыми ответами в `localStorage`. Клик по записи показывает ответ без нового вызова модели.
- **Ошибки.** Пустой ввод, длина, нет ключа, 401/402/429, таймаут, пустой ответ, неверный формат и обрыв связи дают понятное сообщение.
- **Безопасность.** Текст модели вставляется через DOMPurify, остальное через `textContent`.

## Деплой

Репозиторий готов к развёртыванию на Render через `render.yaml`: New → Blueprint, выбрать репозиторий, вписать `PROXYAPI_KEY`. На публичный адрес действует лимит 10 запросов в минуту с одного IP, чтобы не расходовать баланс ключа.
